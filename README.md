# mosaic

Modular AI architecture for composing a persistent core and swappable specialist models into a single agent larger than its active VRAM footprint.

**Mosaic is an active Build Team Two (BT2) project assignment.**

For a fresh or blind project orientation, read:

1. [BT2 Assignment](BT2_ASSIGNMENT.md)
2. [Current Status](CURRENT.md)
3. Draft PR #1 on `project/foundation-v1` for the exploratory foundation, architecture, and predeclared experiments.

The canonical `main` branch intentionally carries only enough orientation to recover project authority and current work without treating the draft architecture as already accepted.
