# P0-NEURAL-COUNT-01 — preregistered narrow learned-state experiment

**Qualification target:** Prove that two separately resident trainable neural specialists can transfer a *learned continuous* state that beats a capacity-limited conventional text-record retrieval baseline. This is an intentionally limited **toy counting task**, not evidence that pretrained LLM specialist partitions share a reasoning Core or that Mosaic beats unrestricted retrieval.

Frozen before looking at heldout scores: 2026-10-26, `experiments/p1_toy_latent_benchmark.py` implementation. A sample contains 16 independent binary event records. Eight query families ask whether the count is at least one of {6,7,8,9,10,11,12,13}; targets are balanced in each family, with counts sampled from {t-2,t-1} for negative and {t,t+1} for positive. Train has 512 unique examples/family, dev 64/family; two disjoint test slices from one seeded PRNG stream have eight cases/family each, four positive and four negative. All 4,736 generated masks must be disjoint across splits, and no heldout labels train the weights.

**Neural handoff:** Source specialist trains a 16→64→32→8 floating-point encoder (learned representation, not discrete JSON answer). Target specialist trains an 8-state+8-query→64→64→2 classifier. Save separate safetensors weights. At evaluation, invoke a source-only process to write 8-dimensional continuous states, exit that process, then invoke a target-only process. The target *entrypoint* loads only the target checkpoint, state tensor and query; both processes nevertheless share host filesystem permissions, so the boundary is procedural, not a security sandbox. A separate comparison process has access to labels and baseline data and replays both checkpoints sequentially to reject fabricated predictions. This tests physical process separation with learned transfer.

**Controls:** RESET only sees the query; FULL_HISTORY receives all 16 records and the query; the originally named ORDINARY_RETRIEVAL comparator receives **the first eight raw bits**, represented by their original indices, and trains its own classifier. No actual BM25, semantic index, or retrieval engine is invoked; the first-eight selection is a fixed-prefix truncation. This is a **bounded eight-record proxy**, *not* unrestricted or independently optimized retrieval. The transferred state costs 32 bytes (eight float32 values), whereas all 16 bits would fit in just two bytes if losslessly packed. Train all conditions with identical examples and fixed epochs, optimizer and seeds.

**PASS criteria:** Each 64-case repeat has at least 5 pp accuracy benefit for learned latent over retrieval, one-sided exact paired binomial p < .05, and at least 80% learned-latent accuracy; baseline full history is reported regardless of result. Source/target process separation and independent weight file SHA256 are mandatory. Report total training/inference CPU time, all confusion matrices and raw predictions. Any failure stays HOLD; no cherry-picked seed or hidden change to the test.

**Limits:** A source learned classifier can outperform retrieval here because it compresses all records before swapping; an unrestricted retrieval context containing every record could match the information available. This experiment does **not** establish broad general neural reasoning superiority or compare two independently pretrained LLMs with a trained adapter. The separate pretrained SmolLM2 tensor-injection probe tests that latter *wiring* only.

**Post-result clarification (do not silently revise frozen gates):** The two disjoint test slices are drawn from one deterministic seeded stream, not independently seeded training replicates. The source/target checkpoints and gate are unchanged. Subsequent zero-state and rolled-state ablations are diagnostic follow-up, not part of the original preregistered result.

**Hostile-review correction:** The initial statement likening first-eight selection to BM25 retrieval was incorrect, and the 32-byte budget does not force loss of any of the original 16 *bits*. The toy narrow gate applies to a deliberately lossy fixed-prefix comparison, not genuine conventional retrieval. The actual broad comparative question remains HOLD even though the frozen arithmetic gate says PASS.
